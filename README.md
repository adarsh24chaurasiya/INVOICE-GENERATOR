# 🧾 Invocraft

A clean and intuitive invoice generator web app that helps you create, manage, and download professional invoices with ease.

🔗 **Live Demo:** [invocraftt.netlify.app](https://invocraft.netlify.app)

## ✨ Features

- 📝 **Fill Once, Generate Instantly** — Add business, client, item, and payment details in one page
- 💰 **Auto Calculations** — Item totals, tax, and subtotal update in real time
- 🌍 **Multi-Currency Support** — Switch between USD, EUR, GBP, INR, and JPY on the fly
- 🇮🇳 **GST & Udyam Fields** — Optional fields built in for Indian businesses
- 🏦 **Bank Payment Details** — Required account number and IFSC so clients can pay you easily
- ✅ **Smart Validation** — Won't generate until required fields are filled correctly
- 💾 **Saved Automatically** — Invoices stay in your browser until you delete them
- ✏️ **Edit Anytime** — Reopen and update any invoice you've already generated
- 📥 **One-Click PDF Download** — Export any invoice instantly
- 📱 **Responsive Design** — Works smoothly across devices

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository

   ```
   git clone https://github.com/your-username/invocraft.git
   ```

2. Open `index.html` in your browser
3. Start generating invoices!
